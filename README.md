# 单词答题游戏

一个专为课堂一体机设计的静态Web单词答题游戏应用。支持中文英文互译学习，具备随机抽题功能，无需服务器即可运行。

## 功能特点

- ✅ **三种答题模式**：中文→英文、英文→中文、随机模式
- ✅ **CSV题库管理**：支持自定义题库文件
- ✅ **随机抽题**：智能随机算法，避免重复
- ✅ **实时统计**：显示答题进度和剩余题数
- ✅ **一体机适配**：大字体、高对比度设计
- ✅ **离线使用**：纯前端实现，无需网络

## 快速开始

### 1. 文件准备
确保以下文件在同一目录下：
- `index.html` - 主页面文件
- `styles.css` - 样式文件
- `script.js` - 功能脚本
- `sample-words.csv` - 示例题库（可选）

### 2. 启动应用
**方法一：直接打开**
1. 双击 `index.html` 文件
2. 系统会自动在默认浏览器中打开

**方法二：本地服务器**（推荐）
```bash
# 如果有Python环境
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server

# 然后在浏览器访问 http://localhost:8000
```

### 3. 使用步骤
1. **选择应用模式**：
   - **讲台模式**：传统的显示答案模式，适合教师讲解
   - **答题模式**：选择题模式，学生可以选择答案
2. **选择内置题库**（推荐）：系统会自动识别data文件夹中的所有CSV文件，选择需要的题库点击"加载题库"
3. **或上传自定义题库**：点击"上传题库文件"，选择CSV文件
4. **选择答题模式**：点击顶部的模式按钮（中文→英文、英文→中文、随机模式）
5. **开始答题**：
   - **讲台模式**：点击"显示答案"查看答案，点击"下一题"继续
   - **答题模式**：从四个选项中选择答案，系统会显示是否正确，然后手动点击"下一题"
6. **查看统计**：底部显示答题进度

## 题库制作

### CSV文件格式
```csv
中文,英文
你好,hello
世界,world
苹果,apple
```

### 制作要求
1. 第一行必须是标题：`中文,英文`
2. 每行一个词条，中文在前，英文在后
3. 用逗号分隔，无多余空格
4. 文件编码为UTF-8

## 界面功能

### 主要区域
- **标题栏**：显示应用名称
- **模式选择**：三种答题模式切换
- **题目显示**：中央大字体显示题目
- **控制按钮**：显示答案和下一题
- **统计信息**：显示答题进度
- **内置题库选择**：快速加载预设题库
- **文件上传**：上传自定义题库文件

### 双模式系统
- **讲台模式**：传统的显示答案模式，适合教师在课堂上讲解使用
- **答题模式**：交互式选择题模式，学生可以从四个选项中选择答案，系统会即时反馈是否正确

### 内置题库
- **智能识别**：系统会自动扫描data文件夹中的所有CSV文件，无需手动配置
- **中文优化**：防止中文文件名被转换成HTML百分号转义符号，确保中文正确显示
- **路径修复**：自动修复文件路径格式，避免重复的data//data/路径错误
- **多重保障**：如果自动扫描失败，系统会尝试使用file-list.json文件，最后使用默认题库
- **基础词汇**：100个常用中英文词汇，适合初学者
- **动态加载**：只需将新的CSV文件放入data文件夹，系统会自动识别并添加到选择列表中
- **文件管理**：支持中文文件名，自动清理显示名称

### 答题模式
1. **中文→英文**：显示中文，回答英文
2. **英文→中文**：显示英文，回答中文
3. **随机模式**：随机显示中文或英文
